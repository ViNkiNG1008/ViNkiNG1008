### 1. CommerceFlow — End-to-End Data Engineering Pipeline

An end-to-end e-commerce data engineering project built using the Brazilian Olist dataset. Implements a Bronze–Silver–Gold architecture to ingest, transform, validate, and model data for analytical consumption.

**Key Implementations**
- Built a Python-based ingestion pipeline with Parquet storage.
- Implemented Pandas and PySpark transformations.
- Developed a 13-task Apache Airflow DAG for pipeline orchestration.
- Designed a dimensional Gold model with 4 dimensions, 3 fact tables, and 7 analytical views.
- Integrated PostgreSQL and Snowflake data warehouses.
- Built interactive Power BI dashboards for business insights.
- Containerized the orchestration environment using Docker Compose.

**Tech Stack:** Python · Pandas · PySpark · Apache Airflow · PostgreSQL · Snowflake · SQL · Power BI · DAX · Docker
